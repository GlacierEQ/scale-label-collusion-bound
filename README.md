# Label Collusion Bound

**Problem space:** data labeling / evaluation integrity (Scale-class public design lens)  
**Innovation:** Screen annotator pairs for unusually high agreement by comparing observed agreement with the expected agreement under independent annotator-specific empirical label marginals.

A flagged pair is **not proof of collusion or misconduct**. It is a deterministic agreement anomaly that warrants independent investigation. Input identity and screening policy are bound into the report receipts.

This repository is complementary to `scale-eval-poison-sentinel` and `scale-agreement-budget-allocator`, but no sibling integration is claimed until executable receipt binding is proven.
